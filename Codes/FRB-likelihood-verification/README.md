# FRB Likelihood Verification

Independent numerical cross-check of the Fast Radio Burst (FRB) likelihood
implementation used across all six cosmological models in this repository.

## What this is

The FRB dispersion-measure likelihood combines a truncated Gaussian for the
cosmological/IGM contribution, `P_cos(DM_cos | z)`, with a log-normal
convolution over the host-galaxy contribution, giving the marginal density
`P(DM_ext | z)`. This folder reimplements both from scratch — independently
of the production MCMC code — and checks that:

1. **The likelihood function is implemented identically across all six
   models.** `P_DM_ext_vectorized` is extracted from each model's
   Baseline+FRB notebook and compared after stripping whitespace/comments,
   since the FRB statistical treatment does not depend on the underlying
   cosmological model (only the model-specific `H(z)` entering the
   Macquart-relation mean `DM_cos_mean` should differ).
2. **Both `P_cos` and its convolution `P(DM_ext | z)` are correctly
   normalized to unity**, checked with adaptive quadrature
   (`scipy.integrate.quad`) across the redshift range of the real FRB
   sample.
3. **The production code's fixed-grid trapezoidal integration** (used in
   every MCMC run, for speed) is compared point-by-point against an
   independent adaptive-quadrature implementation, for every FRB in the
   real sample, quantifying any resolution-driven numerical difference and
   its net effect on the total FRB log-likelihood.

## Where it was applied

The functions are extracted from, and cross-checked against, the
`*_CC_SNe_BAO_FRB.ipynb` Baseline+FRB notebooks under
`Codes/MCMC-Models/GR-based/` and `Codes/MCMC-Models/MG-based/` (LCDM, wCDM, CPL, AB,
HS, ST), and run against the real FRB catalog
(`Data/FRB/frb_catalog.txt`). **Nothing outside this folder is modified** —
every script here only *reads* the production notebooks and the data;
none of the MCMC chains or fitted results are touched or regenerated.

## Files

- `extract_and_diff_functions.py` — extracts `P_DM_ext_vectorized` from the
  six main-analysis notebooks and checks they are functionally identical
  (whitespace/comment-insensitive comparison). Prints a per-model
  identity verdict and writes `extracted_P_DM_ext_functions.txt` (the six
  extracted function bodies, for manual inspection).
- `verify_frb_likelihood.py` — runs the three numerical tests described
  above and writes `results_summary.json` (all numeric results: the
  normalization checks, the production-vs-quadrature comparison, the
  per-FRB relative differences, and the net log-likelihood impact).

`extracted_P_DM_ext_functions.txt` and `results_summary.json` are
generated by running the scripts above; they are not tracked in this
repository (see `.gitignore`) and are regenerated fresh on every run.

## How to reproduce

```bash
source /home/brunowesley/projetos/venv/bin/activate
python3 Codes/FRB-likelihood-verification/extract_and_diff_functions.py
python3 Codes/FRB-likelihood-verification/verify_frb_likelihood.py
```

`extracted_P_DM_ext_functions.txt` and `results_summary.json` in this
